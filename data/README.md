# Training Data

The original training datasets are not included in this repository because
of their large file sizes.

The datasets can be obtained from Kaggle. Search Kaggle using the keywords
below and place the downloaded CSV files in this directory.

| Required file | Kaggle search keywords |
|---|---|
| `crop_recommendation.csv` | `Crop Recommendation Dataset` |
| `soil_quality_dataset.csv` | `Soil Quality Dataset` |
| `Agriculture_price_dataset.csv` | `Agriculture Commodity Price Dataset India` |
| `weather_data.csv` | `Indian Agriculture Weather Dataset` |

After downloading the datasets, rename the files if necessary so that their
filenames match the names above.

These datasets are only required if you want to retrain the machine-learning
models. The trained model artifacts are already included in `models/`, so
they are **not required to run the application**.
